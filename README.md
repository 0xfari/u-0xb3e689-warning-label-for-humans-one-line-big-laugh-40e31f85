Warning Label for Humans: One Line, Big Laugh — Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. A house judge compares lines two at a time on label form, laugh on first read, recognition, label wording, then fit inside 160 characters. Free entry, $5 pool split equally across the top 5. Entries close 2026-11-27 05:20 WIB; blind rounds, results due 2026-12-19.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
